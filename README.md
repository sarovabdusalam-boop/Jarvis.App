# Джарвис — голосовой помощник для Android

Android-приложение с плавающей кнопкой поверх других приложений. Нажми на кружок, произнеси команду — Джарвис выполнит её или отправит вопрос в Gemini и озвучит ответ.

## Установка
Открой вкладку **Releases** этого репозитория и скачай последний APK. Если релиза ещё нет, открой **Actions**, выбери успешный запуск **Build APK** и скачай артефакт **Jarvis-APK**.

## Первый запуск
1. Разреши отображение поверх других приложений.
2. Разреши доступ к микрофону и уведомлениям.
3. Для команд «назад», «домой», «недавние приложения», «уведомления», «скриншот» включи службу специальных возможностей Джарвиса в настройках Android.
4. Для ответов ИИ нажми «Получить бесплатный ключ Google», создай ключ в Google AI Studio и вставь его в приложение. Для Gemini API есть бесплатный тариф с ограничениями по запросам. Лимиты и доступность моделей могут меняться; при исчерпании бесплатной квоты придётся подождать сброса лимита или выбрать другой тариф. Не подключай платный биллинг, если не хочешь платить.
5. На TECNO/HiOS при необходимости разреши автозапуск и установи для батареи режим «Без ограничений».
6. Нажми «Запустить Джарвиса». Плавающий кружок появится поверх приложений. Нажатие начинает запись, повторное нажатие останавливает её.

## Примеры команд
- «Открой YouTube», «запусти Telegram», «открой камеру».
- «Назад», «домой», «недавние приложения», «покажи уведомления».
- «Сделай скриншот», «заблокируй экран».
- Любой обычный вопрос — отправляется в Gemini, ответ произносится вслух.

## Ограничения и конфиденциальность
- Постоянного прослушивания по фразе «Джарвис» пока нет: запись запускается нажатием на плавающий кружок.
- Для распознавания речи обычно нужен интернет и системный сервис распознавания речи.
- Ключ Gemini API хранится локально в настройках приложения. Не публикуй его и не добавляй в репозиторий. На бесплатном тарифе Google может использовать отправленные данные для улучшения продуктов — не передавай личные секреты.
- Служба специальных возможностей не запрашивает чтение содержимого экрана.
- Android и оболочки производителей могут ограничивать работу в фоне.

## Сборка
GitHub Actions автоматически собирает debug APK при каждом push в main/master. Требуются JDK 17, Android SDK и Gradle 8.9.
